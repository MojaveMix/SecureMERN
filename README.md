# SecureMERN

A secure Full-Stack project generator for React and Node.js.

## Current Status

V0.1 — CLI Foundation

## Installation

```bash
npm install
```

## Usage

```bash
secure-mern create my-app
```

## Generated Structure

```text
my-app/
├── client/
├── server/
└── README.md
```
