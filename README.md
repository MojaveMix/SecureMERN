# SecureMERN

A Full-Stack project generator for React and Node.js.

## Current Version

V0.3

## Quick Start

```bash
npx secure-mern create my-app

cd my-app

npm install

npm run dev
```

## Architecture

```text
React + Vite
     ↓
Express API
     ↓
Node.js
```

## API Endpoints

- `GET /api/health`

The development environment automatically starts both the React frontend and the Express API server.
